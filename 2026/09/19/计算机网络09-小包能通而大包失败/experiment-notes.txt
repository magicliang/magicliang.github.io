Chapter 09 experiment notes, 2026-09-20

Scope: Python standard library; existing owned Linux Podman VM; fresh A/R/B
network namespaces and veth pairs for every case. No host default-route,
physical-interface, production-system, package installation or deployment change.
IPv6 DAD remains enabled and is awaited with a ten-second deadline.

Sources checked while implementing:
https://man7.org/linux/man-pages/man2/IP_MTU_DISCOVER.2const.html
https://man7.org/linux/man-pages/man7/ipv6.7.html
https://github.com/torvalds/linux/blob/v6.18/include/uapi/linux/in.h
https://raw.githubusercontent.com/torvalds/linux/v6.18/include/uapi/linux/in6.h
Linux UAPI: IP_MTU_DISCOVER=10, IPV6_MTU_DISCOVER=23,
IP_PMTUDISC_DO=IPV6_PMTUDISC_DO=2. setsockopt success is checked by real execution.
These are Linux ABI constants, not portable socket option numbers.

First attempt stopped before namespace creation: /usr/include/linux/in.h did
not exist in the VM. No headers were installed. The source constants were
checked against upstream Linux v6.18 instead. EXIT trap stopped the VM.

The next run passed eight cases. Its instrumentation recorded server ACK
sent_bytes as zero despite sendto returning three. The counter assignment was
corrected and router interface MTU read-back was added, followed by a fresh run.
The final run.jsonl is generated by that revised script, not edited by hand.

CLI checks: --help exit 0; --version 5 and --size 0 exit 2;
macOS default invocation rejects unsupported environment with exit 1.
Python no-excuse checker: zero violations.

Decoder boundary: untagged Ethernet; IPv4 header length parsed, IPv6 fixed
header with no extension-header traversal. Only this controlled traffic is
classified. Raw frames are retained. Checksum validation and capture-drop
accounting are not implemented. Raw frame observations do not prove delivery
in another environment. Application ACK plus both endpoint captures describe
only this isolated exchange, not a production end-to-end path.

No TCP/MSS negotiation, PLPMTUD algorithm, retransmission, physical NIC/offload
performance or public-network result is claimed. Timeout duration is a bounded
one-second test deadline, not a measured protocol timeout or operational SLO.
