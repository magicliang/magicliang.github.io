分布式系统04 本地验证
日期2026-09-19；Go1.27.0 darwin/arm64。
代码 examples/distributed-systems/kv04/main.go。

命令在examples/distributed-systems目录执行：
GOCACHE=/private/tmp/ds-go-cache go run -race ./kv04 -check
首次沙箱拒绝回环监听，申请本机实验权限后运行成功；最终修正版本退出0：
initial write/read revision=1 value=one
post-sync reply-loss client-error=true
killed/restarted new-pid=true same-id revision=2 read=two
conflict=409 new-id revision=3 old-id revision=1
invalid log tail at offset 185: EOF
log-records=3 incomplete-tail startup-rejected=true unchanged=true
CHECK passed

invalid log tail为预期失败子进程的stderr，并非自检失败。
真实HTTP连接；post-sync故障头使已同步写的响应被主动关闭；
Process.Kill返回成功、Wait收到SIGKILL状态，恢复实例PID不同；
重启GET验证HTTP200、two和revision2；旧操作回放保留revision1；
冲突返回409，新ID生成revision3；完整日志仅3条；坏尾逐字节不变。

go vet ./kv04：退出0。
go run -race ./kv04 -help：退出0，显示-serve/-check。
go run -race ./kv04 unexpected：应用exit status2、go run外层1。

证据等级：本机真实HTTP与子进程恢复验证；非真实多机器集群E2E。
未验证：掉电、内核崩溃、页缓存丢失、设备缓存故障、EIO/ENOSPC注入、
网络文件系统、多写进程、日志位翻转、快照/压缩/校验和、其他Go与OS版本。
不完整末行是受控文件注入，不声称自然故障中观察到该形态。
全站构建与浏览器预览由父线程整合执行，此处不预先宣称通过。

父线程独立复核：最终go run -race ./kv04 -check全部通过；
复读SIGKILL状态断言与bytes.Equal坏尾检查；本机Go1.27.0 Darwin同步源码
