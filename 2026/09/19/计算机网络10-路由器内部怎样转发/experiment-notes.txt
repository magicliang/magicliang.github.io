Chapter 10 local teaching model, 2026-09-20

Run: PYTHONDONTWRITEBYTECODE=1 python3 control.py
Retain chapter 07's sibling asset directory containing forwarder.py.
The import accepts either the source date-prefixed directory or the generated
page asset directory without the date prefix. For manual download, forwarder.py
can instead be placed beside control.py. No dependency package is installed.

The imported Route, Packet, forward and Decision are used directly; chapter 07
is neither copied nor modified. Cost ordering is an explicit teaching choice,
not a claim about preferences in BGP, OSPF, Linux or a hardware router.
Same-prefix equal lowest costs and duplicate candidate names are rejected.
Cost is nonnegative; this CLI scenario requires cost-a < cost-b. Different
prefixes remain separate routes and chapter 07 supplies longest-prefix lookup.

Default candidates: prefix 10.6.2.0/24, A next hop 192.0.2.1 cost 10,
B next hop 192.0.2.2 cost 20. All four observations use the same immutable packet,
destination 10.6.2.9 TTL 64. Computed/installed versions progress as:
1/1 => A; 2/1 => still A; 2/2 => B; 3/3 empty => network-unreachable.
A separate TTL 1 input uses chapter 07's time-exceeded decision.

Verified normal run, --help exit 0, alternate costs 0/1 exit 0,
negative cost, equal costs and noninteger cost exit 2.
Tie and duplicate-name rejection are checked during every normal run.
Python no-excuse checker: zero violations.

No thread, timer, packet serialization, real send, kernel route installation,
ASIC update, RIB/FIB transaction, route daemon or failure recovery is modeled.
Python variable assignment installs an immutable snapshot only. The pending
snapshot demonstrates a possible calculation/installation gap, not an observed
router delay, atomic hardware transition or production routing failure.
