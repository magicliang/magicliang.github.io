1. RFC 1035, DNS, IETF, 1987-11
   https://www.rfc-editor.org/rfc/rfc1035.html
   已读：§4.1.1 的 RCODE 字段与 Name Error 定义。
   支持：NXDOMAIN 是显式 DNS 响应语义，超时不等于 NXDOMAIN。

2. RFC 2308, Negative Caching of DNS Queries, IETF, March 1998
   https://www.rfc-editor.org/rfc/rfc2308.html
   已读：§2.1、§3、§5。
   支持：NXDOMAIN 负答复可被缓存，SOA 信息限定负缓存生命期。

3. RFC 9293, TCP, IETF, 2022-08
   https://www.rfc-editor.org/rfc/rfc9293.html
   已读：§3.8.3 的 SYN 重传要求与§3.10.8 的重传超时处理。
   支持：SYN 可因重传超时失败；单端无 SYN-ACK 不足以定位丢失方向。

4. RFC 8446, TLS 1.3, IETF, 2018-08
   https://www.rfc-editor.org/rfc/rfc8446.html
   已读：§2 的握手概述与§4.4 的认证消息。
   支持：TCP 建连与 TLS 认证是不同阶段；本文未执行 TLS 握手。

5. RFC 9110, HTTP Semantics, IETF, 2022-06
   https://www.rfc-editor.org/rfc/rfc9110.html
   已读：§15.3.1 的 200 (OK) 语义。
   支持：200 表示当次请求成功，不证明整条路径没有重传或其他后端健康。

6. RFC 2923, TCP Problems with Path MTU Discovery, IETF, 2000-09
   https://www.rfc-editor.org/rfc/rfc2923.html
   已读：§2.1 Black Hole Detection 的 Description、Implications 和 How to detect。
   支持：IPv4 DF 包超过下一跳 MTU 而所需 ICMP 反馈未到达时，小传输可成功而大传输可停滞。
